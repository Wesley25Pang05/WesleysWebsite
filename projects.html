Custom Editable Tower Defense Game

This project was one I wanted to work on for a while. I recently learned TypeScript a little before I started working on this project and decided to use Phaser to create pathing, enemies, and towers. This however is not the traditional tower defense game. Currently, there is a theme with this Tower Defense Game, but it can easily be changed with just a few clicks and images. The enemies have health, the pathing can easily be changed, and the towers can be changed within a few seconds. There are custom classes for the Towers as a base to help others create their own towers easily, along with custom stats of the enemies and coordinates for the pathing. It is one of the largest projects I have done, with over two thousand lines of code excluding each tower, which includes about three hundred lines each. This, however, is a private project and will be only shared during interviews.

Automated Multiplayer Word-Guessing Bot

This project was inspired by an old game called Bomb Party that people play over the internet. You may have seen variations of this game, but basically, you are given two or three letters, and you need to find words that include those letters consecutively. I decided to make a bot that can automatically input words that are correct, with adjustable speeds and length. Speed was important because if you do not guess in time, you end up losing lives. Length was important because using almost all letters in the game, you regain a life. I programmed this mostly using Python's pyautogui and OpenCV.

Two Player Chess App

One of my large high school projects is a game of chess built with JavaScript and HTML. The two-user game was started when I was in my junior year, and that was when I went ahead to teach myself JavaScript and substantial HTML from home, motivated by my growing interest in chess; after all, I played chess almost every day. The game is a mixture of all the basic chess functionalities: the pawns get moves; the king and rook go together; en passant and check get detected. Checkmate is still rather buggy, but once you are in checkmate, you can no longer make your move. I wanted to go one step ahead of myself to work with a more complex project, which made me think of a 1-vs-1 chess game, for my love of coding and love for the game. In the future, I have plans to create a chess engine like Stockfish, but for now, all things equal, I would like to be a master of multiplayer chess.

Wordle with Discord Bot Development

In my sophomore year in high school, I developed a Java program that was based on the popular online game Wordle and the Discord platform. I planned to create a project that was both entertaining and useful in the Discord world, where docs are being created all the time just for performing tasks using commands. I developed a Discord bot that randomly generates five-letter words for the users to play Wordle with, and at the same time, it runs it gathers data so everyone can play their own game. I was not willing to be the only one playing, so I introduced the bot to several Discord servers where players could then join together and support one another. To begin with, the users invite the bot to their server, run the code with the bot using an API key, and then they can issue commands such as play Wordle or guess "word". This project was made before Discord added its own Wordle gaming system.
